--- title: "Useful Bookmarklets" ---

Drag the following bookmarklets to your browser's bookmark folder or bar. When on a specifc page, click on the bookmarklet to run it.

General Utilities {% include permalink.html hash="general-utilities" %}

Career Site Publish

Used to automate publishing of a careers site. Will publish 20 files at a time until task is completed. Use on any publishing admin page. Open dev console to see status of publishing.

Sitemap (Career Site)
Video (Career Site) Images (Career Site) Selector Search (Career Site)

Used to retrieve and output a spreadhseet of all pages on a careers site based on sitemap.xml. Works on both QA and Production domains. The Selector Search bookmarklet prompts for a CSS class, attribute, or selector (e.g. .my-button or data-fancybox) and reports every matching element found on each page.
